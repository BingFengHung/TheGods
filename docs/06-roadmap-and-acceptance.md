# 06｜開發里程碑與驗收

狀態：M0 規劃文件；M1–M5 尚未開發。里程碑用通過條件推進，不能只按日曆宣告完成。

| 階段 | 交付 | 通過條件 | 依賴 |

| M2 可玩切片 | 一城一野、任務鏈、回合戰鬥、成長、背包與存檔 | A07–A10；15–20 分鐘完整循環 | M1 外觀／效能關卡 |
| M3 多人 Alpha | 帳號、兩人再到五人組隊、同圖、雲端存檔、重連 | A11–A16；真實兩裝置測試 | M2；獨立長連線伺服器 |
| M4 系統擴充 | 四職業、神仙／寵物／坐騎成長、合成、交易、洞府初版 | 各系統案例＋A17；資料可追溯 | M3；內容與美術量產能力 |

M1 若角色不像，先修角色，不增加地圖掩蓋問題。M2 可使用獨立練習存檔；M3 才可稱為多人線上版本。各階段完成時交付版本連結、提交、測試結果與已知限制。

## 2. 工作量與資源假設

以下為初步排程推估，不是完成承諾：假設一名全職遊戲／全端工程師、一名全職角色／場景美術，兼職 QA；相關素材可重建且範圍不持續改動。

| 階段 | 估計日曆工作週 | 不確定性 |
| --- | --- | --- |
| M1 | 4–8 週 | 角色修稿、穿模、八方向分層與圖集記憶體 |
| M2 | 4–6 週 | 戰鬥規則研究、操作與第一條任務鏈 |
| M3 | 4–8 週 | 登入、多人一致性、持久化與弱網 |
| M4 | 8–16 週 | 四職業、社交經濟與資產量 |
| M5 | 待內容盤點後估算 | 全地圖、全裝備與歷代內容數量未知 |

上述階段合計是 20–38 週到 M4 的粗估，不含 M5 全內容補齊；部分製作可交錯，不能直接當成固定交付日期。單人兼做美術通常更久。先用 M1 實際每套服裝／每武器族工時修正估算；本次不產生任何費用或訂閱。

| ID | 操作／情境 | 必須看到的結果 |

| A04 騎乘 | 八方向上／下騎與移動 | 騎士與鞍具對齊，前後翼及尾巴遮擋正確 |
| A05 載入 | 首次開啟、圖集失敗、快速切裝 | 有清楚進度；失敗可重試，場上不出現隱形角色或敵人 |
| A06 手機 | 兩方向橫放、開鍵盤、切前背景、由主畫面啟動 | 可操作、按鈕在安全區、無觸控位移；效能記錄達預算 |

| A09 核心 | 固定初始狀態、seed 與指令重播 | 相同規則版本產生相同事件及結果 |
| A10 存檔 | 換裝與接任務後關閉、重開、升級 schema | 進度不丟失；M2 本機與 M3 線上資料明確分開 |
| A11 多人 | 兩台裝置同房，一人換装／移動／出招 | 對方看到一致外觀、位置與戰鬥事件 |
| A12 冪等 | 指令及領獎請求重送十次 | 行動／獎勵僅生效一次，沒有複製物品 |
| A13 權限 | 冒用別人 actorId／物品、偽造傷害或金額 | 伺服器拒絕；合法玩家資料不改變 |

| A17 經濟 | 雙方交易同時取消／確認、背包滿、金額不足 | 原子轉移或回復，資產總量守恆 |

| A20 發佈 | 前後端錯版、回滾、資料庫還原演練 | 有清楚更新／維護訊息，可恢復已確認的穩定版本 |

## 4. 自動化與人工的界線

- 單元／資料測試：回合、狀態、目標、物品限制、任務前置、外觀解析、所有圖集方向／幀引用完整性。
- 整合測試：資料庫交易、重領、重連、跨 session、服務重啟、錯版拒絕。
- E2E：新角色→接任務→戰鬥→穿戴→存檔→重開；雙客戶端交互。
- 資產檢查只能發現缺件、格式與幀差，不能證明「角色很像」。視覺需要同尺度對照及人工審閱。
- PWA／真機驗收由實際 Safari 與 Android 主畫面模式補充；無裝置時必須標未測，不可填通過。
- 負載分階段：雙人→五人隊伍→二十戰鬥實體→同圖五十人→試營運一百同時在線。記錄環境及瓶頸，再決定擴容。

## 5. 風險與處置

| 風險 | 最早處置 | 影響 |
| --- | --- | --- |
| 截圖不足、版本混雜 | M1 前建立版本／資產缺口清單；缺資料用研究稿標記 | 原作一致性、全內容工期 |
| 角色美術反覆不符合 | 先做一角色，無特效比較，保留可修改來源 | 阻擋量產，不阻擋資料研究 |
| 分層遮擋／圖集爆量 | M1 測最複雜衣袍武器組合，量測解碼尺寸 | 必要時比較即時 3D 備案 |
| 手機不支援方向鎖定 | 轉向提示與能力偵測 | 不阻擋橫向遊玩 |
| 斷線或背景停用 | 伺服器計時、快照與指令冪等 | 防止卡死、重複動作與獎勵 |
| 只有靜態前端無後端 | M3 獨立 WSS／DB 部署 | 不得誤稱線上遊戲完成 |
| 全內容數量未知 | 先凍結盤點清單再估 M5 | 不用虛假百分比報告進度 |

每次交付報告附：實作範圍、已通過項、未測項、缺陷、下一個關卡。測試結果必須來自實際版本；本次只有文件檢查，不含遊戲測試。
