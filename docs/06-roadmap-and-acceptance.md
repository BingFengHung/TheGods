# 06｜單機優先里程碑與驗收

> 0.1 實作已開始：本文件保留前期規劃，完成情形及技術調整請以 [09 實作現況](09-implementation-status.md) 為準；不能將規劃表格視為已交付功能。

更新：2026-10-12，v0.2。M1／M2 已有初版實作，尚未完成正式驗收；M3–M5 未啟動。後端調整到最後，並為可選階段，不自動啟動。

## 1. 里程碑

| 階段 | 交付 | 通過條件 | 後端需求 |
| --- | --- | --- | --- |
| M0 | 規劃、參考、任務、免費方案 | 文件與 repo 一致 | 無 |
| M1 | 角色換裝與動畫驗證場、紅龍、手機 PWA 外殼 | A01–A06 | 無 |
| M2 | 15–20 分鐘單機完整流程、本機進度及備份 | A07–A12 | 無 |
| M3 | 四職業、地圖、任務、神仙／戰寵／坐騎、合成與單機內容擴充 | 各模組與內容清單驗收 | 無 |
| M4 | 完整單機基準版、離線包、真機最佳化與免費靜態發佈 | A13–A18；確認畫面和玩法效果 | 無 |
| M5（可選、最後） | 後端可行性與預算研究，必要時才開發同步／多人 | 使用者決定需要後端後另定目標 | 屆時再選 |

單機版本不用登入，不以假多人畫面取代其他真實玩家。多人聊天、交易、洞府戰等列入 M5 延後項，不阻擋 M4 單機完成。

M1 外觀不合格時先修角色；M2 不因能戰鬥就省略存檔／離線；M3 不先建立雲端帳號。M4 可獨立作為最終成品。

## 2. 初步工期假設

假設一名全職遊戲／全端工程師、一名全職美術與兼職 QA：M1 約 4–8 工作週、M2 約 4–6 週；M3 依角色與內容盤點後估算；M4 依真機問題與缺陷估算。這些是規劃推估，非交付承諾。

先以 M1 實際角色、裝備與動畫製作速度修正排程。不保留舊的多人開發週數在單機排程內，也不估算尚未決定的 M5 時程。自動化工具能協助開發，但不能以此跳過美術與真機驗收。

## 3. 單機驗收

| ID | 情境 | 結果 |
| --- | --- | --- |
| A01 外觀 | 同方向、同尺度參考比較 | 臉髮、比例、衣甲、武器及坐騎有對照與差異紀錄 |
| A02 換裝 | 三服裝×兩頭部×三武器及卸裝 | 18 組獨立混搭生效，不只是換色或全身皮膚 |
| A03 動畫 | 八方向、八個基礎動作 | 無缺幀、跳臉、飄武器；部件同相位 |
| A04 騎乘 | 八方向待機／移動、上下騎 | 騎士掛點、翼尾與鞍具遮擋正確 |
| A05 載入 | 圖集失敗、首次載入、快速切裝 | 有回饋與重試，人物／敵人不隱形 |
| A06 手機 | 左右橫向、安全區、鍵盤、主畫面模式 | 全流程可觸控，無座標偏移 |
| A07 循環 | 建角色到任務、頭目、領獎、換裝與交付 | 15–20 分鐘單機流程可完成 |
| A08 戰鬥 | 防禦、施法、無 MP、死亡、無效目標、撤退 | 指令合法性、狀態與動畫正確 |
| A09 重播 | 相同初始狀態、亂數及指令 | 相同規則產生一致結算 |
| A10 保存 | 安全邊界後關閉重開 | 裝備、任務及進度正確恢復 |
| A11 備份 | 匯出後匯入新槽、損毀／未知版本匯入 | 正確恢復或清楚拒絕，原存檔不被覆蓋 |
| A12 原子性 | 結算中斷、重試十次、交易失敗 | 獎勵只領一次；失敗不顯示存檔成功 |
| A13 離線 | 完整下載後飛航模式遊玩、關閉重開 | 探索、戰鬥、掉落、任務、換裝與存檔均可用 |
| A14 更新 | 戰鬥中出新版、下載中斷、舊分頁回來 | 安全邊界更新、不混用資產、不覆蓋新進度 |
| A15 儲存邊界 | 多分頁同存檔、容量不足、格式升級 | 單一寫入者、版本保護、可恢復與備份 |
| A16 暫停 | 直向、鎖屏、退背景 30 秒／2 分鐘 | 回合安全暫停與恢復，不重領、不跳結果 |
| A17 完整性 | 凍結單機內容清單逐項核對 | 全部有證據；未知、延期與多人項目分開 |
| A18 發佈 | 真機 30 分鐘、免費 HTTPS、SW 與子路徑 | 不黑屏、不丟檔、不持續增加資產引用、可離線重開 |

視覺需人工對照；資產格式檢查不能證明角色相似。Safari 分頁、iOS 主畫面模式、Android 分頁與安裝模式分別測試；無真機就標未測。

## 4. M5 才需要的驗收

若使用者之後選擇多人，再建立 B01 雙客戶端狀態一致、B02 權威結算與指令冪等、B03 權限與非法物品、B04 重連／伺服器恢復、B05 資料庫交易及還原、B06 免費配額與超限測試。

這些不是目前 CI、M1–M4 交付或開發環境的必要條件。本機存檔可修改，將來線上角色如何建立／遷移需另定，不承諾直接匯入線上經濟。

## 5. 風險與交付紀錄

| 風險 | 現階段處置 |
| --- | --- |
| 角色不像、資料缺角度 | 先做一角色，無特效對照，未知面標研究稿 |
| 圖集遮擋／記憶體 | 先驗證最複雜衣袍與武器混搭，測解碼預算 |
| 無後端預算 | M1–M4 純靜態＋本機保存，不開通雲端服務 |
| 清除網站資料導致進度遺失 | 存檔匯出匯入、備份提醒與錯誤回復 |
| 免費靜態單檔限制 | 分包資產，發布前驗證大小 |
| 未取得全部內容 | 逐項盤點，不填虛假的完成率 |

每次交付附版本／提交、可用範圍、測試紀錄、未測項與缺陷。初版程式與測試證據見 09 文件；真機仍待測。
