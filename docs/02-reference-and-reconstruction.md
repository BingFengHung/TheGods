## 2. 視覺規格

| 項目 | 參考觀察 | 本專案做法 |
| --- | --- | --- |
| 鏡頭 | 固定斜俯視角，人物與地面有縱深 | 正交／近正交投影；先以地磚方向估相機，M1 對照後定案 |
| 人物 | 頭部較大、短身比例，但有立體材質與服裝厚度 | 有結構的臉、髮束與服裝；逐名量測比例，不套統一誇張 Q 版模板 |
| 色彩 | 地面低彩度，角色與法術顏色突出 | 地景控制對比，輪廓與材質區分；不依靠全身高亮遮掩細節 |
| 武器 | 持握、長度與方向清楚影響剪影 | 右／左手掛點、武器前後遮擋隨動作調整 |
| 坐騎 | 龍身、翅膀、尾部、鞍具與騎士構成整體 | 坐騎與騎士分件，同一騎乘掛點與節奏 |
| 介面 | 藍／綠底、金橘邊框、頭像、血條、文字與指令 | 保留視覺語彙，重新配置手機可按的尺寸 |
| 地面 | 石板接縫、斜向紋理、局部裝飾 | 分塊地圖、遮擋物及碰撞資料分開 |
| 特效 | 冰晶、光圈、浮字有前後層次 | 地面圈、施法、命中及飄字分層，不遮住操作目標 |

相機角度、角色頭身比、原始動畫幀數與色票尚未量測完成，不能在此宣稱精確數值。M1 以同尺度、同朝向、無特效版本做側對側比較。

## 3. 證據與缺口

| 問題 | 目前證據 | 下一個動作 |
| --- | --- | --- |
| 裝備是否會改變外觀 | 使用者明確要求；SRC-02 描述多部位紙娃娃 | 建立獨立部位與每幀遮擋規格 |
| 原版是否使用即時 3D | 截圖不足以證實 | 不假定原引擎；按視覺與效能選重製技術 |
| 八方向是否完全對稱 | 無背面／連續影片 | 逐方向重建與核對，禁止未驗證的左右鏡像代替 |
| 回合規則與神仙操作 | 選單可見，詳細流程未知 | 補完整戰鬥錄影，記錄點擊、倒數、出手與結算 |
| 原作完整版本 | 百科橫跨多次改版 | 建立版本清單及新增／刪除差異 |
| 全角色／全裝備／全地圖 | 五張截圖未涵蓋 | 按百科入口盤點，標記缺頁與缺圖 |
| 紅龍步態與騎士姿勢 | 單張近景 | 補各方向與移動參考；先做可修正的骨架稿 |
| 數值與經濟 | 尚無完整表格交叉驗證 | 暫定資料隔離；標明來源與測試狀態 |

可以先完成技術及可見方向的重建。未知背面可先做明確標記的設計稿，但不能標記「已忠實復刻」。若使用者後續有原始角色圖、裝備圖、多方向影片或可使用模型，按此表補齊；不是本次規劃提交的阻塞。
