## 4. 任務記錄格式

每個實作任務至少記錄：問題與玩家影響、採用的參考、具體交付、依賴、驗收案例、實際測試結果、提交、圖片／影片、尚未完成部分。涉及畫面時附無特效的比較圖；涉及多人時附兩端狀態和伺服器事件序號。

未核實的原作規則用「暫定設計」標示；找到新證據後先更新資料／規格與差異，再改程式。不要讓一個猜測在多處程式碼硬編碼。
