## 4. 最後才評估的 M5（可選）

M1–M4 不安裝登入 SDK、不建立雲端資料庫、不寫遊戲房間伺服器、不把多人當作單機完成門檻。

| ID | 順序 | 後續事項 |
| --- | --- | --- |
| DEC-501 | 最先 | 單機效果確認後，決定是否真的需要同步或多人 |
| COST-501 | DEC-501 後 | 依實際人數比較免費配額、休眠、持久化與超限行為 |
| SPIKE-501 | COST-501 後 | 小規模後端實驗，選定架構，不提前承諾永久免費 |
| NET-501 | 選型後 | 必要的身分、權威回合、同步、重連與驗證 |
| SOCIAL-501 | 基礎連線後 | 真實玩家聊天、交易、組隊、洞府等功能 |
| QA-501 | M5 最後 | 多人一致性、存檔隔離、免費配額與資料恢復 |

Node／Colyseus、Cloudflare Durable Objects 與 Supabase 都只是候選；不因找到免費服務就現在開通或開發後端。

## 5. 任務紀錄與待決事項

任務包含問題、參考、交付、依賴、驗收、實際版本、圖片／影片及未完成項。畫面需無特效對照，存檔需關閉重開與損毀案例，離線需飛航模式操作證據。

待決事項：完整內容版本與數量、補充角色多方向素材、神仙與戰寵精確規則、真機最低裝置、靜態託管選擇。全部後端決策延至 M5；本次無需註冊服務或支付費用。
