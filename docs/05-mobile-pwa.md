更新：2026-10-12，v0.2。M1–M4 交付單機版；本文件的尺寸、效能與流量數字為設計預算，尚未實測。以手機真機完成核心流程為驗收，不以桌面模擬器可開啟代替。

## 1. 橫向配置

保留參考畫面的頭像、血條、小地圖、戰場與底部指令語彙，按拇指可達範圍重新配置；不能將桌面完整介面等比例縮小。

| 區域 | 探索狀態 | 戰鬥狀態 |
| --- | --- | --- |
| 左上 | 頭像、HP／MP、隊伍 | 出戰單位、HP／MP 與狀態 |
| 上中 | 收合的任務／提示 | 回合、可暫停倒數、已提交狀態 |
| 右上 | 小地圖、設定 | 隊伍／敵方摘要，必要時收合 |
| 中央 | 地圖、角色、NPC 與路徑 | 友方右下、敵方左上的可配置站位 |
| 左下 | 紀錄入口、可選移動搖桿 | 戰鬥紀錄、寵物／單位切換 |
| 右下 | 互動、背包、任務 | 攻擊、技能、道具、防禦等分類入口 |
| 底邊 | 安全區與系統手勢空間 | 同左；按鈕不能被 Home indicator 蓋住 |

單一層只展開一個主要面板。點擊技能後顯示可選目標，選目標再確認；施放前可取消，提交後顯示等待。敵人密集時提供目標名稱列表，避免只能點到最前方人物。

主要按鈕目標至少 48 × 48 CSS px，一般可點擊元素至少 44 × 44；周圍保留間距。內文字級原則 14–16 CSS px，必要狀態不可縮成不可讀的小字。以上是專案目標，不宣稱為所有平台的強制規範。

## 2. 操作與適配

- 點擊地面尋路；點 NPC／傳送點先顯示互動狀態，不因手指抖動誤開介面。
- 虛擬搖桿只在探索出現；支援多指但不得讓 UI 點擊穿透到地圖。
- 道具／技能點擊可看說明，長按只作捷徑，所有必要動作都可單次點擊完成。
- 背包採頁籤或分頁，裝備預覽可旋轉方向、播放動作；換裝後有明確完成／失敗回饋。
- 支援安全區 `env(safe-area-inset-*)`、`viewport-fit=cover` 與動態可視高度；監聽 viewport 改變但避免每幀重排。
- 世界視野適應寬高比，不拉伸人物；DOM 字級與按鈕保持實際 CSS 尺寸，不能隨 canvas 解析度縮小。
- 角色命名或存檔命名鍵盤出現時只重排輸入區，暫停地圖點擊；IME 組字期間不以 Enter 誤送。
- 首次明確互動後啟用音訊；返回前景恢復音訊狀態，尊重靜音設定。
- 降低動態效果設定可關閉鏡頭震動、減少閃爍／粒子；血條以數字與狀態圖示補充，不只依賴顏色。
- 手機旋轉或改尺寸不可重置角色、重開戰鬥或重複領獎。

## 3. 方向與安裝

manifest 設定 landscape 是偏好，`screen.orientation.lock()` 並非所有瀏覽器都能使用。[TECH-02／03](02-reference-and-reconstruction.md)

流程：載入外殼 → 檢查方向 → 直向顯示「請將手機橫放」 → 橫向進入。支援的裝置可在玩家手勢後嘗試鎖定；失敗繼續使用轉向提示，不能卡住。不得用整頁 CSS 旋轉假裝鎖定，造成觸控座標錯亂。

單機轉直向或退背景時安全暫停回合與倒數，旋回後恢復；不依賴伺服器計時。多人行為僅在可選 M5 重新設計。

PWA 外殼需包含：

- 正確 MIME type 的 manifest、穩定 id、name、short_name、start_url、scope、display 與 orientation。
- 192／512 圖示、maskable 圖示及 Apple touch icon；按各平台實際顯示檢查裁切。
- HTTPS、scope 內的 Service Worker、可導覽的離線頁、安裝與更新說明。
- 支援的瀏覽器顯示安裝入口；iPhone 提供 Safari 分享／加入主畫面的說明，按實際系統版本核對，不依賴自動安裝提示事件。
- 根路徑與子路徑部署均可正確載入圖集、manifest、SW 及深連結；若採 GitHub Pages 路徑，必須測試 /TheGods/，不能硬寫所有資產為 /assets/。

manifest 的路徑和服務範圍隨最後部署位置定案。此階段沒有提供可安裝網址。

## 4. 完整單機離線與快取

| 資料 | 策略 | 離線行為 |
| --- | --- | --- |
| 外殼與離線入口 | 版本化預快取 | 開啟已下載遊戲與存檔管理 |
| 圖集、地圖、音效 | 雜湊 URL、按內容包下載 | 完整包可直接遊玩，缺包顯示需要下載 |
| 內容 manifest | 記錄包版本、雜湊與下載完成狀態 | 只使用最後完整且相容的內容組合 |
| 遊戲規則與 AI | 與客戶端一起打包 | 本機回合、掉落、任務及成長正常運作 |
| 角色、背包、任務、戰果 | IndexedDB 原子交易 | 離線照常儲存與讀取 |
| 備份 | 使用者匯出／匯入存檔 | 不需要帳號、雲端或伺服器 |

首次須連網下載對應內容，第一次完全離線無法安裝尚未取得的遊戲。「可離線」只在必需檔案完整且通過校驗後顯示；下載中斷可以續抓缺件，不能把半個包標成完成。

單機進度不是可任意清除的資產快取。瀏覽器／OS 仍可能清除網站資料，因此提供備份提醒、檔案匯出及安全匯入；使用 persistent storage 能力時偵測支援，不能保證瀏覽器一定保留資料。更換網域會更換儲存來源，部署遷移前引導匯出。

SW 更新遵循安裝、等待、啟用生命週期。[TECH-04](02-reference-and-reconstruction.md) 戰鬥中不強制 reload；回到安全畫面、進度提交成功、新資產完整且存檔格式可遷移後才啟用。多分頁需避免舊分頁覆寫新進度；更新失敗保留上一完整版本。

M1–M4 不提供登入、WebSocket、雲端獎勵或其他必要的遊戲 API 請求。飛航模式可完成已下載內容的接任務、戰鬥、領獎、換裝及存檔流程。

## 5. 效能與測試預算

基準實機先選 iPhone 13 級別及一台中階 Android；開發時記錄實際型號、OS、瀏覽器版本、電量與測試情境，不宣稱目前已有這些裝置測試結果。

| 指標 | 初始目標與測量方式 |
| --- | --- |
| 畫面流暢度 | 20 戰鬥實體＋代表性特效，10 分鐘記錄；目標 60 FPS，至少 p95 frame time ≤33.3ms |
| 輸入回饋 | 本機點擊至按鈕／選取圈可見反應 p95 ≤100ms，不含網路結算 |
| 資產記憶體 | 角色／地圖活躍 RGBA 圖集預算 ≤128 MiB；含 mipmap／render target 另記，不能當成整個 App 總記憶體 |
| 首屏外殼 | 壓縮傳輸 ≤3 MiB，字型按需載入 |
| 首段可玩內容 | 累計傳輸目標 ≤15 MiB；以 10Mbps／100ms RTT 預算約 20 秒，記錄真實值並優化 |
| 其餘內容 | 地圖區域與角色裝備分包，不一次預載全世界 |
| 穩定性 | 連續 30 分鐘切圖、換裝與戰鬥，不黑屏、不崩潰、不持續增長資產引用 |
| 長寬比 | 667×375、812×375、844×390、932×430 CSS viewport；另測 iPad 與桌面 |

若達不到預算，先減少粒子、非關鍵動畫更新、裝置像素比與場外資產；保留人物、敵人、目標圈及主要操作。不能用隱藏角色來換取幀率。

自動化：載入、manifest、離線殼、更新、核心觸控流程。實機必測：Safari 分頁與主畫面模式、Android 分頁與安裝模式、左右橫向、鍵盤、背景 30 秒／2 分鐘、內容包弱網下載中斷、飛航模式完整遊玩與重新載入。瀏覽器自動化不能代替 iOS PWA 的真機行為。
