## 2. 體驗與資料界線

玩家直接在裝置建立角色，不需註冊；城鎮接任務、野外探索、回合戰鬥、獲得經驗和道具、可視換裝、培養神仙／戰寵與坐騎。可由玩家操作的隊伍與 AI 敵人均在本機運作，不以假玩家宣稱多人連線。

參考資料顯示四個職業類別：劍客、藥師、謀士、仙道，以及裝備、戰寵、坐騎、神仙、任務、地圖、合成與轉生等入口。這僅確認類別存在，未取得的完整公式與動作不可寫成已核實。[資料來源](02-reference-and-reconstruction.md)

單機規則保留可調整的資料定義。版本、隊伍容量、神仙控制、技能消耗、出手與掉落公式需補證；暫定值明示為 TheGods 測試資料。

| 系統 | 單機交付 | 階段 |

| 角色與換裝 | 分件裝備、多方向與完整動作、騎乘 | M1 |

| 地圖與任務 | 城鎮、野外、NPC、迷宮、傳送、任務鏈 | M2 樣本，M3 擴充 |

| 背包與成長 | 商店、穿戴、經驗、物品與本機進度 | M2 |
| 四職業與養成 | 技能、神仙、戰寵、坐騎、合成、轉生 | M3 |
| 單機完整內容 | 凍結內容清單內地圖、任務、敵人與裝備 | M3–M4 |

涉及其他真實玩家的功能不納入單機完整版完成率；保留將來路線，但不會先建空伺服器或假登入介面。後端永遠不做也不影響單機成品的成立。

## 4. 第一段單機流程（M2）

一城一野、一戰鬥場景、三名功能 NPC、一條至少五步的 15–20 分鐘任務鏈、一職業六技能、三種一般敵人與一頭目、一戰寵與一神仙樣本。至少十二個裝備／道具定義，可視裝備沿用 M1 資產。

完成接任務→探索→戰鬥→獎勵→換裝→交付→關閉→重新開啟的完整循環。飛航模式下可繼續已下載內容、取得獎勵及儲存；不是只有設定頁能離線。

單機退背景或旋轉至直向時可安全暫停。戰鬥中關閉程式後恢復到已提交的回合邊界，避免重複獎勵；細節見存檔設計。

## 5. 完整版界定

每項內容記錄 id、類型、目標版本、來源、確認程度、美術狀態、程式狀態及測試證據。圖像、動作與玩法仍需逐項核對；未知總量不填虛假的完成百分比。

M4 完成代表「單機基準版」：凍結的單機內容清單通過視覺、玩法、存檔、離線及真機驗收。M5 是之後可選的產品決策，不是 M4 的依賴。

順序：角色與動作品質→單機完整循環→單機內容與穩定性→使用者確認效果→最後評估後端與費用。
