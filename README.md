# TheGods｜封神 2：仙界傳網頁重製計畫

**狀態：開發前規劃 v0.1，2026-10-12（Asia/Taipei）。尚未開始遊戲程式與正式美術製作，也沒有可遊玩的版本。**

目標是以《封神 2：仙界傳》及使用者提供的五張參考截圖為基準，製作以手機橫向操作為主、可安裝的 PWA 線上角色扮演遊戲。完整重製是長期目標；本次先交付可執行的開發規劃、內容缺口、技術決策與驗收標準。

最優先的要求是角色外觀：裝備必須實際改變角色的頭部、服裝及武器，且變化需反映在移動、戰鬥、多方向與坐騎狀態。只換人物立繪、數值、顏色或一張全身貼圖，不構成換裝完成。

## 已選定的方向

- **畫面：**固定斜俯視角、具有體積與材質感的角色、石板場景、雙方列陣、藍底金橘框介面。比例與色彩以截圖比較為準。
- **角色：**統一骨架製作模型與裝備，離線輸出八方向分層動畫圖集；網頁端以紙娃娃方式組合。先完成一名角色的換裝品質驗證，通過後再大量生產。
- **前端：**TypeScript、Phaser、Vue 與 Vite；遊戲渲染和介面分工，版本於建置階段驗證並鎖定。
- **連線：**Node.js／Colyseus 房間伺服器、PostgreSQL 持久化；角色資產由 CDN 分區載入。
- **玩法：**城鎮探索、任務、回合制戰鬥、職業與技能、神仙、戰寵、坐騎、可視換裝，再依清單擴充社交、交易、合成、轉生與大型內容。
- **平台：**iPhone 與 Android 橫向優先；直向顯示轉向提示，支援加入主畫面。線上進度由伺服器保管。

## 下一個具體交付

M1「角色換裝與動畫驗證場」：一種基礎體型、三套可辨識服裝、兩種頭部裝備、三種武器外型、八方向動作、一隻紅色龍形坐騎及石板測試場景。提供同角度對照、動作錄影與真機測試記錄。

這是正式內容量產之前的品質關卡。後續 M2 為完整短流程，M3 才標示為多人線上 Alpha；不能把單機測試場宣稱成完整線上遊戲。

## 規劃限制

五張圖片涵蓋四種主要畫面，其中兩张為相同戰鬥畫面的不同截圖。它們不足以還原全部背面、完整動畫、全地圖與原版數值。本計畫把可確認內容、重製設計與待補資料分開記錄；未知項目不視為已完成或原作事實。

本儲存庫目前只包含文件。沒有建置、測試或安裝遊戲的指令；相關指令會隨 M1 工程建立。
