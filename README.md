# TheGods｜山海行旅

手機橫向、單機優先的角色扮演 PWA。**目前是 0.1.5 第一章單機原型，不是完整內容或視覺驗收完成版。** 遊戲不需要帳號、遊戲伺服器、雲端資料庫或付費 API。

> **最新修正（2026-10-14）：0.1.5 統一三套裝備的肩、肘、腕長度，掌心與武器握點共用位置，並修正裙甲長度、完整靴子與腳底接地。** [手腳比例對照](docs/visuals/limb-proportions-comparison.webp) · [實際動作圖](docs/visuals/limb-actions.webp)。現有圖集使用 2D 關節裝配；完整人物來源、八方向素材與騎乘坐姿仍依 [重建計畫](docs/11-visual-rebuild-plan.md) 製作，尚未完成真機與風格驗收。

## 現在可以玩什麼

- 青嵐鎮、雲隱山道：點地移動、NPC 對話、地圖切換、寶匣與補給。
- 一段可完成的主線：接任務、清除妖物、挑戰玄岩守衛、回城領獎。
- 玩家與靈狐的回合戰鬥：斬擊、全體霜華、回春、守禦、丹藥、撤退；包含掉落與升級。
- 分件換裝：三套衣甲、三種武器、兩種頭飾、銀／黑髮色。裝備同時改變外觀與能力。
- 赤雲坐騎、人物方向預覽、待機／行走／攻擊／施法的分件動作。
- 本機自動存檔、戰鬥回合接續、JSON 匯出／匯入、上一份存檔復原。
- 橫向介面、直向提示、安全區、安裝圖示、Service Worker 完整資源預載。

人物不是把整張立繪替換成另一張圖。頭、冠、軀幹、裙甲、手臂、手、靴與武器分開組合；持握、手臂及衣襬會依動作調整。**目前只有前／後頭部素材及方向變換，不是八方向逐幀美術完成品；兩種選項是髮色，不是兩款髮型。** 詳見[現況與限制](docs/09-implementation-status.md)。

## 開始遊玩

1. 橫放手機，按「進入旅程」。
2. 按左側任務卡「前往目標」，找守山人接任務。
3. 再按任務卡，前往山道清除妖物，收集碎片。
4. 挑戰玄岩守衛；生命不足可用丹藥、回春或回城免費休息。
5. 回城覆命。隨時可用下方選單換裝、騎乘與查看背包。

戰鬥依序「選指令 → 點場上目標或下方目標按鈕 → 確認出招」。確認前可重新選擇，不會扣除資源；防禦和撤退也需確認。靈狐目前自動協助。地圖與任務追蹤會帶角色走到出口後換區，點擊地面可以取消帶路。設定內可以匯出備份，換瀏覽器／裝置或清除網站資料前請保留。

## 本機開發

Node.js 20 以上，沒有第三方執行或建置相依套件，不需要 `npm install`。

```sh
npm test
npm run check
npm run build
python3 -m http.server 4173 --directory dist
```

在本機瀏覽器開啟 `http://localhost:4173`；不要直接雙擊 HTML。正式環境部署 `dist/` 到 HTTPS 靜態託管即可。手機透過區網 HTTP 開啟不等於 HTTPS／localhost，通常無法啟用離線服務。

安裝：iPhone 使用 Safari「分享 → 加入主畫面」；支援安裝的 Android 瀏覽器使用「安裝應用程式」。先連網開啟，於設定確認「離線資源已就緒」後再測試飛航模式。私人預覽託管的初次開啟可能需要擁有者驗證；遊戲本身沒有帳號系統。

## 程式位置

| 路徑 | 用途 |
| --- | --- |
| `src/app.mjs` | 觸控、介面、探索與戰鬥呈現 |
| `src/commands.mjs` | 待確認指令、目標檢查與過期回合阻擋 |
| `src/layout.mjs` | 可見視窗、戰場鏡頭、觸控座標與人物命中範圍 |
| `src/core.mjs` | 純函式規則、任務、屬性與存檔驗證 |
| `src/draw.mjs` | 分件角色、騎乘、敵人、場景及特效 |
| `src/storage.mjs` | IndexedDB 交易、版本衝突與備用儲存 |
| `src/sw.js` | 離線資源與更新 |
| `src/assets/` | 隨遊戲一同下載的圖集、場景及圖示 |
| `tests/` | 規則、流程、回合恢復與儲存例外測試 |
| `scripts/` | 資源檢查與靜態建置；內容雜湊隔離快取版本 |
| `dist/` | 可直接部署的靜態輸出 |
